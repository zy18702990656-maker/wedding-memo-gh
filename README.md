# 婚礼通知备忘录

记录「已通知婚礼的朋友名单」、跟踪出席状态并记份子钱的轻量 PWA。纯前端，数据存在设备本地，不上传服务器。

## 线上地址

https://zy18702990656-maker.github.io/wedding-memo-gh/

## 功能

### 份子钱（v4.2）

- 列表每行一个「¥」按钮，点开直接记金额，8 档快捷金额（100~2000）+ 手输
- 记完默认自动标记为「确认出席」，可在弹层里取消勾选
- 只收实物时金额留空、方式里写清楚，台账单独标「实物」，不计入总额
- 汇总面板：总额 / 已随礼 / 人均 / 最高 / 未记，跟着当前标签范围走
- 筛选「已随礼 / 未随礼」，排序「份子钱多→少 / 少→多」（没记的永远沉底）
- 礼金台账：总额、按标签分摊、完整明细、未记名单一键筛出，可复制文字或导出 CSV（带 BOM，Excel 不乱码）

### 名单与出席

- 朋友记录增删改查，姓名必填
- 标签分组：亲戚 / 大荔发小 / 初中同学 / 高中同学 / 大荔跳舞朋友 / 西安跳舞朋友，可自定义
- 四种出席状态循环切换：已通知 → 确认出席 → 待确认 → 不来
- 批量录入：姓名支持换行、空格、逗号、顿号混用分隔
- 统计面板（总人数 / 确认出席 / 待确认 / 不来），随标签分组变化，可点击筛选
- 按姓名、标签、备注搜索；按状态筛选；按日期或拼音排序；按标签分组视图
- 换机搬数据：同步码一键复制粘贴，支持智能合并（按最后修改时间取新）与覆盖
- 备份与恢复：导出 / 导入 JSON，自动快照（最近 8 次改动可回滚）
- 合并保护：对面那份没记份子钱、本机记了的，合并时保留本机金额，不会被旧数据冲掉
- 删除后可撤销
- PWA：可添加到主屏幕，离线可用

## 技术

- 纯 HTML / CSS / JS，无构建步骤、无依赖
- localStorage 存储
- Service Worker 离线缓存

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式（浅色天蓝主题，移动端优先） |
| `app.js` | 全部业务逻辑 |
| `sw.js` | Service Worker，离线缓存 |
| `manifest.webmanifest` | PWA 清单 |
| `icon-180.png` / `icon-512.png` | 主屏幕图标（必须完全不透明，iOS 会把透明区填成黑色） |
| `make_icons.py` | 图标生成脚本，无第三方依赖 |

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```

## 改完图标后

```bash
python3 make_icons.py
```

同时记得把 `sw.js` 里的 `CACHE` 版本号加一，否则旧缓存不会更新。
